# Windows 10 Cursors

A clean, vanilla Windows 10 cursor pack for users who accidentally deleted or replaced their default Windows cursor files.

This project is meant to restore the standard Windows 10 cursor set back to its original state.

## What this is

This repository contains the default Windows 10 cursor files in a ready-to-use format. If your system has lost the standard cursor pack, you can restore it by copying these files into the Windows cursor directory.

## Important note

These are the default Windows 10 cursors, not custom or third-party cursor themes.

## Install Instructions

1. Download this repository or extract the files to a folder on your computer.
2. Open File Explorer and go to:
   `C:\Windows\Cursors`
3. Copy the cursor files from this project into that folder.
4. Open the Mouse settings:
   - Press `Win + I`
   - Go to `Bluetooth & devices` > `Mouse`
   - Click `Additional mouse settings`
   - Open the `Pointers` tab
5. Select the default Windows cursor scheme or browse to the restored default cursor files if needed.
6. Click `Apply` and then `OK`.

## If you want to restore the default pointer scheme

After copying the cursor files into `C:\Windows\Cursors`, you can do the following:

1. Open the Mouse Properties window.
2. Go to the `Pointers` tab.
3. Click the `Scheme` dropdown.
4. Choose the default Windows scheme.
5. Click `Apply`.
